Topic: CSS Selectors and Properties

1. Objective

To understand different types of CSS selectors and properties and learn how to apply styles to HTML elements to improve the appearance and design of webpages.

2. Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to control the design and layout of HTML webpages.

CSS helps developers make webpages attractive by adding colors, fonts, backgrounds, borders, spacing and alignment.

CSS works together with HTML:

- HTML provides the structure of a webpage.
- CSS provides the styling and appearance of a webpage.

3. CSS Syntax

CSS follows a simple syntax consisting of a selector, property and value.

Syntax

selector {
    property: value;
}

Example

h1 {
    color: blue;
    font-size: 30px;
}

Explanation:

- Selector: "h1" selects the heading element.
- Property: "color" specifies the text color.
- Value: "blue" defines the color of the heading.
- Declaration: A property and its value together form a declaration.

4. What are CSS Selectors?

CSS selectors are used to select HTML elements that we want to style.

They help apply different styles to specific elements or groups of elements.

There are several types of CSS selectors.

5. Types of CSS Selectors

A. Universal Selector (*)

The universal selector selects all HTML elements on a webpage.

It is represented by an asterisk (*) symbol.

Example:

* {
    margin: 0;
    padding: 0;
    font-family: Arial;
}

Explanation:

This selector applies the specified styles to all elements on the webpage.

B. Element Selector

The element selector selects HTML elements using their tag names.

Example:

h1 {
    color: blue;
}

p {
    font-size: 18px;
}

Explanation:

- All h1 headings will appear blue.
- All paragraph elements will have a font size of 18 pixels.

C. ID Selector (#)

The ID selector is used to style a specific HTML element.

It is represented by the hash (#) symbol.

Example:

HTML:

<h1 id="heading">Welcome to CSS</h1>

CSS:

#heading {
    color: red;
    text-align: center;
}

Explanation:

The "#heading" selector applies styling to the element having the ID named heading.

An ID should be unique within an HTML page.

D. Class Selector (.)

The class selector is used to apply the same style to multiple HTML elements.

It is represented by a dot (.) symbol.

Example:

HTML:

<p class="text">Welcome to HTML.</p>
<p class="text">Welcome to CSS.</p>

CSS:

.text {
    color: green;
    font-size: 20px;
}

Explanation:

Both paragraphs receive the same styling because they have the same class name.

E. Group Selector

The group selector is used to apply the same style to multiple different HTML elements.

A comma (,) is used to separate selectors.

Example:

h1, h2, p {
    color: purple;
    text-align: center;
}

Explanation:

The same styling is applied to all h1, h2 and paragraph elements.

F. Descendant Selector

The descendant selector selects elements that are present inside another element.

Example:

HTML:

<div>
    <p>This is a paragraph inside a div.</p>
</div>

CSS:

div p {
    color: blue;
}

Explanation:

This selector applies styling to paragraph elements located inside a div element.

6. CSS Properties

CSS properties define how HTML elements should look on a webpage.

Some commonly used CSS properties are:

A. Color Property

The color property is used to change the text color.

h1 {
    color: red;
}

B. Background Color Property

The background-color property is used to change the background color of an element.

body {
    background-color: lightblue;
}

C. Font Size Property

The font-size property controls the size of the text.

p {
    font-size: 20px;
}

D. Font Family Property

The font-family property changes the style of the text.

h1 {
    font-family: Arial;
}

E. Text Alignment Property

The text-align property is used to align text.

h1 {
    text-align: center;
}

Common values:

- left
- right
- center
- justify

F. Border Property

The border property adds a border around an HTML element.

div {
    border: 2px solid black;
}

G. Margin Property

The margin property creates space outside an element's border.

div {
    margin: 20px;
}

H. Padding Property

The padding property creates space between the content and the element's border.

div {
    padding: 15px;
}

7. Practical Example Using CSS Selectors and Properties

The following program demonstrates different CSS selectors and properties together.

HTML Code

<!DOCTYPE html>
<html>
<head>
    <title>CSS Selectors</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h1 id="heading">Welcome to CSS</h1>

    <p class="text">CSS is used to style webpages.</p>

    <p class="text">It makes websites attractive.</p>

    <div>
        <p>This paragraph is inside a div.</p>
    </div>

    <h2>Learning Web Development</h2>

</body>
</html>

CSS Code (style.css)

* {
    font-family: Arial;
}

body {
    background-color: lightyellow;
}

#heading {
    color: blue;
    text-align: center;
}

.text {
    color: green;
    font-size: 18px;
}

div p {
    color: red;
}

h2 {
    background-color: lightblue;
    padding: 10px;
}

Explanation

- The universal selector applies Arial font to all elements.
- The element selector styles the body.
- The ID selector changes the main heading.
- The class selector styles both paragraphs.
- The descendant selector changes the paragraph inside the div.
- The h2 selector adds a background color and padding.

8. Difference Between ID and Class Selectors

ID Selector| Class Selector
Uses "#" symbol| Uses "." symbol
Identifies a unique element| Can be used for multiple elements
Example: "#heading"| Example: ".text"
Used for specific elements| Used for groups of elements

9. Advantages of CSS Selectors

1. They help select specific HTML elements.
2. They make webpage styling easier.
3. They reduce repeated CSS code.
4. They help maintain consistent website design.
5. They allow developers to apply different styles to different elements.
6. They improve the organization and readability of CSS code.
