# MongoDB Basics

## Aim

To understand the fundamentals of MongoDB, learn about NoSQL databases, collections, documents, and basic MongoDB commands.

## 1. Introduction to MongoDB

MongoDB is a popular NoSQL database used to store and manage data.

Unlike traditional relational databases, MongoDB stores data in flexible, JSON-like documents.

It is commonly used in modern web applications, especially MERN Stack applications.

## 2. What is a Database?

A database is an organised collection of data that allows users to store, access, update, and manage information easily.

**Example:** In a Hospital Appointment System, a database can store patient details, doctor information, and appointment records.

## 3. What is NoSQL?

NoSQL stands for "Not Only SQL".

It refers to databases that do not follow the traditional table-based relational structure.

MongoDB is a NoSQL database that stores information in documents.

## 4. Features of MongoDB

- **Flexible Schema:** Documents can have different fields.
- **Document-Based:** Stores data in JSON-like documents.
- **Scalable:** Can handle large amounts of data.
- **High Performance:** Supports efficient data operations.
- **Easy Integration:** Works well with Node.js and other technologies.

## 5. MongoDB Terminology

| Term | Description |
|---|---|
| Database | Stores collections of data |
| Collection | A group of related documents |
| Document | A single record containing data |
| Field | A key-value pair inside a document |
| `_id` | A unique identifier for each document |

## 6. Database vs Collection vs Document

MongoDB organises data in three main levels:

- **Database:** Contains collections.
- **Collection:** Contains documents.
- **Document:** Contains individual records.

**Example:**

Database: `HospitalDB`

Collection: `patients`

Document:

```json
{
  "name": "Muskan",
  "age": 20,
  "department": "Cardiology"
}
```

## 7. MongoDB vs SQL

| SQL Database | MongoDB |
|---|---|
| Relational database | NoSQL database |
| Stores data in tables | Stores data in collections |
| Uses rows and columns | Uses documents and fields |
| Usually has a fixed schema | Supports flexible schemas |
| Uses SQL queries | Uses MongoDB commands and query methods |

## 8. Basic MongoDB Commands

The following commands can be executed using MongoDB Shell (`mongosh`).

### 1. Show Databases

```javascript
show dbs
```

Displays the available databases.

### 2. Create or Switch Database

```javascript
use HospitalDB
```

Switches to the HospitalDB database. MongoDB creates it when data is first stored in it.

### 3. Show Current Database

```javascript
db
```

Displays the name of the current database.

### 4. Create a Collection

```javascript
db.createCollection("patients")
```

Creates a collection named patients.

### 5. Insert a Document

```javascript
db.patients.insertOne({
    name: "Muskan",
    age: 20,
    department: "Cardiology"
})
```

Inserts one document into the patients collection.

### 6. Display Documents

```javascript
db.patients.find()
```

Displays the documents stored in the patients collection.

## 9. Practical Example

**Step 1:** Open MongoDB Shell.

**Step 2:** Select the database.

```javascript
use HospitalDB
```

**Step 3:** Create a collection.

```javascript
db.createCollection("doctors")
```

**Step 4:** Insert doctor information.

```javascript
db.doctors.insertOne({
    name: "Dr. Sharma",
    specialization: "Cardiology",
    experience: 10
})
```

**Step 5:** Display the stored information.

```javascript
db.doctors.find()
```

**Expected Output:**

```javascript
[
  {
    _id: ObjectId("..."),
    name: "Dr. Sharma",
    specialization: "Cardiology",
    experience: 10
  }
]
```

*Note: MongoDB automatically generates a unique `_id` for each document. The actual ObjectId will be different.*
