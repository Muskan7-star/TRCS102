DAY 3: HTML Lists

Objective

Learn how to create different types of lists in HTML to organize content clearly and improve webpage readability.

---

Introduction

HTML provides different types of lists to display related items in an organized way. Lists make web pages easier to read and understand.

There are three types of lists in HTML:

1. Ordered List ("<ol>")
2. Unordered List ("<ul>")
3. Description List ("<dl>")

---

1. Ordered List ("<ol>")

An ordered list displays items in a numbered format.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Ordered List</title>
</head>
<body>

<h2>Programming Languages</h2>

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

</body>
</html>

---

2. Unordered List ("<ul>")

An unordered list displays items using bullets.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Unordered List</title>
</head>
<body>

<h2>Fruits</h2>

<ul>
    <li>Apple</li>
    <li>Mango</li>
    <li>Orange</li>
</ul>

</body>
</html>

---

3. Description List ("<dl>")

A description list is used to display a term and its description.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Description List</title>
</head>
<body>

<h2>Web Technologies</h2>

<dl>
    <dt>HTML</dt>
    <dd>Used to create the structure of a webpage.</dd>

    <dt>CSS</dt>
    <dd>Used to style the webpage.</dd>

    <dt>JavaScript</dt>
    <dd>Used to make webpages interactive.</dd>
</dl>

</body>
</html>

---

Nested List

A nested list is a list inside another list.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Nested List</title>
</head>
<body>

<h2>MERN Stack</h2>

<ul>
    <li>Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>React</li>
        </ul>
    </li>

    <li>Backend
        <ul>
            <li>Node.js</li>
            <li>Express.js</li>
        </ul>
    </li>

    <li>Database
        <ul>
            <li>MongoDB</li>
        </ul>
    </li>
</ul>

</body>
</html>

---

Key Points

- "<ol>" creates a numbered list.
- "<ul>" creates a bulleted list.
- "<li>" defines a list item.
- "<dl>" creates a description list.
- "<dt>" defines the term.
- "<dd>" defines the description.
- Lists can be nested inside other lists.

---

What I Learned

- How to create ordered, unordered, and description lists.
- How to use the "<li>" tag to add list items.
- How nested lists help organize related information.
- The importance of lists in creating structured and user-friendly web pages.
