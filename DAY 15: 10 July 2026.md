Day 15 – Props, State and Hooks in React.js

1. Introduction

Today, I learned about Props, State and Hooks in React.js. These concepts help us make React applications dynamic and interactive.

- Props are used to pass data from one component to another.
- State is used to store and manage changing data inside a component.
- Hooks are special React functions that allow functional components to use React features.

2. What are Props in React?

Props stands for Properties. Props are used to pass data from a parent component to a child component.

Features of Props

- Props help in sharing data between components.
- Props are read-only.
- Props make components reusable.
- A child component cannot directly change the props received from its parent.

Example of Props

App.jsx

function Student(props) {
  return <h2>My name is {props.name}</h2>;
}

function App() {
  return (
    <div>
      <Student name="Muskan" />
      <Student name="Priya" />
    </div>
  );
}

export default App;

Output:

My name is Muskan
My name is Priya

In this example, the App component passes names to the Student component using props.

3. What is State in React?

State is used to store data that can change over time in a React component.

For example:

- Counter value
- Login status
- User information
- Button status

When state changes, React updates the component's display automatically.

Example of State using useState

import { useState } from "react";

function App() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>Counter: {count}</h2>

      <button onClick={() => setCount(count + 1)}>
        Increase
      </button>
    </div>
  );
}

export default App;

Output:

Initially, the counter displays 0. Whenever the user clicks the Increase button, the value increases by 1.

Explanation

- "useState(0)" creates a state variable with an initial value of 0.
- "count" stores the current value.
- "setCount" updates the state.
- "onClick" handles the button click event.

4. What are Hooks in React?

Hooks are special functions in React that allow functional components to use features such as state and side effects.

Hooks were introduced in React 16.8.

Commonly Used Hooks

1. useState

- Used to create and update state.
- Helps manage changing data in a component.

2. useEffect

- Used to perform side effects in a component.
- Examples include fetching data, updating the document title and setting up subscriptions.

3. useContext

- Used to access data shared through React Context without passing props through every component.

Rules of Hooks

1. Always call Hooks at the top level of a React component or custom Hook.
2. Do not call Hooks inside loops or conditions.
3. Hooks should be used inside React function components or custom Hooks.

5. What is useEffect?

The useEffect Hook is used to perform side effects in React components.

Example

import { useEffect } from "react";

function App() {

  useEffect(() => {
    console.log("Component loaded");
  }, []);

  return <h2>Welcome to React</h2>;
}

export default App;

Output on the webpage:

Welcome to React

Console output:

Component loaded

The empty dependency array "[]" means this effect runs after the component is first displayed.

6. Difference Between Props and State

Props| State
Props are passed from parent to child.| State is managed inside a component.
Props are read-only.| State can be updated.
Used to share data.| Used to manage changing data.
Cannot be directly changed by the child.| Updated using a state setter function.

7. Practical Example: Props and State Together

import { useState } from "react";

function Student(props) {
  const [marks, setMarks] = useState(50);

  return (
    <div>
      <h2>Student Name: {props.name}</h2>
      <h3>Marks: {marks}</h3>

      <button onClick={() => setMarks(marks + 5)}>
        Increase Marks
      </button>
    </div>
  );
}

function App() {
  return <Student name="Muskan" />;
}

export default App;

Output:

Initially:

Student Name: Muskan
Marks: 50

After clicking the button:

Student Name: Muskan
Marks: 55

In this example, the student's name is passed through props, while marks are managed using state.
