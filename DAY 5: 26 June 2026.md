Topics: HTML Links, Images and Introduction to CSS

1. Objective

To understand how to add hyperlinks and images to webpages using HTML and learn the basics of CSS for styling and designing webpages.

2. Introduction

HTML is used to create the structure of webpages. Links and images are important elements that make websites more interactive and attractive.

- HTML Links: Used to connect one webpage to another webpage or website.
- HTML Images: Used to display pictures, graphics and other visual content.
- CSS: Used to style webpages by adding colors, fonts, backgrounds, spacing and layouts.

3. HTML Links

HTML links are also known as hyperlinks. They allow users to navigate from one webpage to another webpage or an external website.

The "<a>" (anchor) tag is used to create hyperlinks.

Syntax

<a href="URL">Link Text</a>

Here:

- "<a>" defines the hyperlink.
- "href" specifies the destination address.
- Link Text is the clickable text displayed on the webpage.

Example

<!DOCTYPE html>
<html>
<head>
    <title>HTML Links</title>
</head>
<body>

    <h2>My Favorite Websites</h2>

    <a href="https://www.google.com">Visit Google</a>
    <br><br>

    <a href="https://www.youtube.com">Visit YouTube</a>

</body>
</html>

Explanation

The anchor tag creates clickable links. When a user clicks on the link, the browser opens the specified webpage.

4. Types of HTML Links

HTML supports different types of links.

A. External Links

External links connect a webpage to another website.

Example:

<a href="https://www.wikipedia.org">Visit Wikipedia</a>

B. Internal Links

Internal links connect different pages within the same website.

Example:

<a href="about.html">About Us</a>

C. Email Links

Email links allow users to open their email application to send a message.

Example:

<a href="mailto:example@gmail.com">Send Email</a>

D. Open Link in New Tab

The "target="_blank"" attribute opens a link in a new browser tab.

Example:

<a href="https://www.google.com" target="_blank">
    Open Google
</a>

5. HTML Images

Images are used to make webpages visually attractive and informative.

The "<img>" tag is used to insert an image into an HTML webpage.

Syntax

<img src="image.jpg" alt="Description">

Important attributes:

- "src": Specifies the image path or URL.
- "alt": Provides alternative text if the image cannot be displayed.
- "width": Sets the image width.
- "height": Sets the image height.

Example

<!DOCTYPE html>
<html>
<head>
    <title>HTML Images</title>
</head>
<body>

    <h2>My Image</h2>

    <img src="flower.jpg"
         alt="Beautiful Flower"
         width="300"
         height="200">

</body>
</html>

Explanation

The "<img>" tag displays an image on the webpage. The "src" attribute specifies the image location, while the "alt" attribute describes the image.

Note: The "<img>" tag is an empty element and does not require a closing tag.

6. Image as a Link

We can also make an image clickable by placing the image tag inside an anchor tag.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Image as Link</title>
</head>
<body>

    <h2>Click on the Image</h2>

    <a href="https://www.google.com">
        <img src="flower.jpg"
             alt="Flower"
             width="200">
    </a>

</body>
</html>

When a user clicks the image, the linked website opens.

7. Introduction to CSS

CSS stands for Cascading Style Sheets.

It is a stylesheet language used to control the appearance and layout of HTML webpages.

CSS helps developers make websites attractive by adding colors, fonts, backgrounds, borders, spacing and different layouts.

Uses of CSS

1. Changes text colors and font styles.
2. Adds background colors and images.
3. Controls spacing and alignment.
4. Adds borders to elements.
5. Creates attractive webpage layouts.
6. Helps make webpages responsive.

8. Types of CSS

There are three main ways to apply CSS to HTML.

A. Inline CSS

Inline CSS is written directly inside an HTML element using the "style" attribute.

Example:

<!DOCTYPE html>
<html>
<body>

    <h1 style="color: blue;">
        Welcome to HTML
    </h1>

    <p style="color: green;">
        This is an example of inline CSS.
    </p>

</body>
</html>

B. Internal CSS

Internal CSS is written inside the "<style>" tag in the HTML document's "<head>" section.

Example:

<!DOCTYPE html>
<html>
<head>
    <title>Internal CSS</title>

    <style>
        h1 {
            color: blue;
            text-align: center;
        }

        p {
            color: green;
            font-size: 18px;
        }
    </style>

</head>
<body>

    <h1>Welcome to CSS</h1>

    <p>CSS makes webpages attractive.</p>

</body>
</html>

C. External CSS

External CSS is written in a separate ".css" file and connected to the HTML document using the "<link>" tag.

HTML File (index.html):

<!DOCTYPE html>
<html>
<head>
    <title>External CSS</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h1>Welcome to Web Development</h1>

    <p>Learning HTML and CSS.</p>

</body>
</html>

CSS File (style.css):

h1 {
    color: blue;
    text-align: center;
}

p {
    color: green;
    font-size: 18px;
}

External CSS is useful because the same stylesheet can be used for multiple webpages.

9. Difference Between Inline, Internal and External CSS

Inline CSS| Internal CSS| External CSS
Written inside an HTML element| Written inside the style tag| Written in a separate CSS file
Uses style attribute| Uses style tag| Uses link tag
Applies to a specific element| Applies to one HTML page| Can style multiple pages
Suitable for small styling changes| Suitable for single-page styling| Suitable for larger websites

10. Basic CSS Syntax

CSS follows a simple structure consisting of a selector, property and value.

Syntax:

selector {
    property: value;
}

Example:

h1 {
    color: red;
    font-size: 30px;
}

Explanation:

- Selector: Selects the HTML element to style.
- Property: Defines what style will change.
- Value: Defines the setting of that property.

11. Advantages of CSS

1. Makes webpages attractive and visually appealing.
2. Separates webpage structure from design.
3. Reduces repeated styling code.
4. Makes website maintenance easier.
5. Provides control over fonts, colors and layouts.
6. Helps create responsive and user-friendly websites.
