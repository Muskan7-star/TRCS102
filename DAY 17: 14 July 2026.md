## Introduction to Express.js

## Aim
To understand the basics of Express.js and learn how to create a simple web server using Node.js and Express.js.

## 1. Introduction to Express.js

Express.js is a web application framework for Node.js. It makes backend development easier by providing simple methods to handle HTTP requests, responses, and routing.

It is commonly used to develop APIs and web applications.

## 2. Why Use Express.js?

- Makes backend development easier.
- Handles HTTP requests and responses.
- Provides routing functionality.
- Helps in creating REST APIs.
- Connects the frontend with the backend.

## 3. Important Concepts

| Concept | Description |
|---|---|
| Express.js | A web framework for Node.js |
| Server | Receives requests and sends responses |
| Request (req) | Information sent by the client |
| Response (res) | Information sent by the server |
| Routing | Handling different URL paths |
| Middleware | Functions that execute during the request-response cycle |

## 4. Installing Express.js

First, create a project folder and open it in VS Code.

Run the following commands in the terminal:

```bash
mkdir express-demo
cd express-demo
npm init -y
npm install express
```

**Explanation:**
- `mkdir express-demo` – Creates a new folder.
- `cd express-demo` – Moves into the folder.
- `npm init -y` – Creates a package.json file.
- `npm install express` – Installs Express.js.

## 5. Creating a Simple Express Server

Create a file named `server.js` and write the following code:

```javascript
const express = require('express');

const app = express();

app.get('/', (req, res) => {
    res.send('Welcome to Express.js!');
});

app.listen(5000, () => {
    console.log('Server is running on port 5000');
});
```

## 6. Code Explanation

1. `require('express')` – Imports Express.js.
2. `express()` – Creates an Express application.
3. `app.get()` – Handles GET requests.
4. `req` – Represents the incoming request.
5. `res` – Represents the response.
6. `res.send()` – Sends a response to the client.
7. `app.listen()` – Starts the server on the specified port.

## 7. Running the Program

Run this command in the terminal:

```bash
node server.js
```

**Output:**

```text
Server is running on port 5000
```

Open the following URL in your browser:

```text
http://localhost:5000
```

**Browser Output:**

```text
Welcome to Express.js!
```

## 8. Introduction to Routing

Routing means defining how an application responds to requests made to different URLs.

Example:

```javascript
app.get('/home', (req, res) => {
    res.send('Welcome to Home Page');
});

app.get('/about', (req, res) => {
    res.send('Welcome to About Page');
});
```

When the user visits `/home`, the server displays the Home Page message. When the user visits `/about`, it displays the About Page message.
