1. Introduction

Today, I learned about DOM Manipulation and Events in JavaScript.

DOM stands for Document Object Model. It allows JavaScript to access and change HTML elements, content, styles, and attributes.

DOM manipulation makes webpages interactive and dynamic.

2. What is DOM?

The Document Object Model represents an HTML document as a tree of objects.

JavaScript uses the DOM to interact with webpage elements.

Example of HTML:

<!DOCTYPE html>
<html>
<head>
    <title>DOM Example</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Learning JavaScript DOM</p>
</body>
</html>

In this example, the heading and paragraph are HTML elements that JavaScript can access through the DOM.

3. Selecting HTML Elements

JavaScript provides different methods to select HTML elements.

A. getElementById()

It selects an element using its ID.

let heading = document.getElementById("title");

console.log(heading);

B. getElementsByClassName()

It selects all elements having the specified class name.

let items = document.getElementsByClassName("box");

console.log(items);

C. getElementsByTagName()

It selects elements using their tag name.

let paragraphs = document.getElementsByTagName("p");

console.log(paragraphs);

D. querySelector()

It selects the first element matching a CSS selector.

let heading = document.querySelector("#title");

console.log(heading);

E. querySelectorAll()

It selects all elements matching a CSS selector.

let paragraphs = document.querySelectorAll("p");

console.log(paragraphs);

4. Changing HTML Content

We can change the content of an HTML element using JavaScript.

The "innerHTML" and "textContent" properties are commonly used.

Example:

<h2 id="heading">Welcome</h2>

<script>
    document.getElementById("heading").textContent = "Hello JavaScript!";
</script>

Output:

The heading changes from "Welcome" to "Hello JavaScript!"

5. Changing CSS Styles Using JavaScript

JavaScript can also change the CSS styles of HTML elements.

Example:

<h1 id="title">Hello World</h1>

<script>
    let heading = document.getElementById("title");

    heading.style.color = "blue";
    heading.style.backgroundColor = "yellow";
</script>

Output:

The heading appears with blue text and a yellow background.

6. What are JavaScript Events?

An event is an action that happens on a webpage.

Examples include:

- Clicking a button.
- Moving the mouse.
- Pressing a keyboard key.
- Submitting a form.
- Loading a webpage.

JavaScript can respond to these events and perform specific actions.

7. Common JavaScript Events

Event| Description
onclick| Occurs when an element is clicked.
onmouseover| Occurs when the mouse moves over an element.
onmouseout| Occurs when the mouse leaves an element.
onkeydown| Occurs when a keyboard key is pressed.
onchange| Occurs when an input value changes.
onsubmit| Occurs when a form is submitted.

8. Event Handling Using addEventListener()

The "addEventListener()" method attaches an event handler to an HTML element.

Example:

<!DOCTYPE html>
<html>
<body>

    <button id="btn">Click Me</button>

    <script>
        document.getElementById("btn").addEventListener("click", function() {
            alert("Button Clicked!");
        });
    </script>

</body>
</html>

Output:

When the user clicks the button, an alert message appears saying "Button Clicked!"

9. Practical Example: Change Text on Button Click

HTML Code:

<!DOCTYPE html>
<html>
<head>
    <title>DOM Manipulation</title>
</head>
<body>

    <h2 id="message">Welcome to My Website</h2>

    <button id="btn">Change Text</button>

    <script src="script.js"></script>

</body>
</html>

JavaScript Code (script.js):

let button = document.getElementById("btn");

button.addEventListener("click", function() {
    document.getElementById("message").textContent =
        "Text Changed Successfully!";
});

Output:

Initially, the webpage displays "Welcome to My Website".

After clicking the button, the text changes to "Text Changed Successfully!"

10. Difference Between innerHTML and textContent

innerHTML| textContent
Gets or sets HTML content.| Gets or sets text content.
Can interpret HTML tags.| Treats content as plain text.
Useful for inserting HTML elements.| Useful for displaying or changing text.
