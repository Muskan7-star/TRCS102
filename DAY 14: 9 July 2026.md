1. Introduction

Today, I learned about JSX and React Components.

React is a JavaScript library used to build user interfaces. JSX makes it easier to write HTML-like code inside JavaScript, while components help divide a webpage into small, reusable parts.

2. What is JSX?

JSX stands for JavaScript XML.

It is a syntax extension for JavaScript that allows us to write HTML-like code inside JavaScript.

React uses JSX to describe how the user interface should look.

Example:

function App() {
    return (
        <div>
            <h1>Hello World!</h1>
            <p>Welcome to React.</p>
        </div>
    );
}

export default App;

Output:

A webpage displays the heading "Hello World!" and the paragraph "Welcome to React."

3. Rules of JSX

Some important rules of JSX are:

1. JSX must return a single parent element.
2. All tags must be properly closed.
3. Use "className" instead of "class" for CSS classes.
4. JavaScript expressions are written inside curly braces "{}".
5. Use camelCase for most HTML attributes, such as "onClick".

Example:

function App() {
    const name = "Muskan";

    return (
        <div className="container">
            <h1>Hello, {name}!</h1>
        </div>
    );
}

export default App;

Output:

Hello, Muskan!

4. JavaScript Expressions in JSX

We can use JavaScript variables and expressions inside JSX with curly braces.

Example:

function App() {
    const a = 10;
    const b = 20;

    return (
        <div>
            <h2>Addition</h2>
            <p>Result: {a + b}</p>
        </div>
    );
}

export default App;

Output:

Addition
Result: 30

5. What are React Components?

Components are reusable and independent parts of a React application.

They help divide a webpage into smaller sections, making the code easier to manage and understand.

Examples of components:

- Header
- Footer
- Navigation Bar
- Login Form
- Product Card

6. Types of React Components

React components are commonly written in two ways.

A. Functional Components

Functional components are JavaScript functions that return JSX.

function Welcome() {
    return <h1>Welcome to React!</h1>;
}

export default Welcome;

B. Class Components

Class components are created using JavaScript classes and extend React's Component class.

import React, { Component } from "react";

class Welcome extends Component {
    render() {
        return <h1>Welcome to React!</h1>;
    }
}

export default Welcome;

Functional components are commonly used in modern React development.

7. Using Components Inside Another Component

One component can be used inside another component.

Example:

Header.jsx

function Header() {
    return <h1>My Website</h1>;
}

export default Header;

App.jsx

import Header from "./Header";

function App() {
    return (
        <div>
            <Header />
            <p>Welcome to my website.</p>
        </div>
    );
}

export default App;

Output:

My Website
Welcome to my website.

8. What are React Fragments?

Fragments allow us to group multiple JSX elements without adding an extra HTML element to the page.

Example:

function App() {
    return (
        <>
            <h1>Hello</h1>
            <p>Welcome to React.</p>
        </>
    );
}

export default App;

9. Difference Between JSX and HTML

JSX| HTML
Used in React applications.| Used to structure webpages.
Uses "className" for CSS classes.| Uses "class" for CSS classes.
JavaScript expressions can be written using "{}".| JavaScript is not directly written as JSX expressions.
All elements must be properly closed.| Some HTML elements can be written without closing tags.
