1. Introduction

Today, I learned about React.js and its basic concepts.

React.js is a popular JavaScript library used to build user interfaces, especially for web applications. It helps developers create interactive and dynamic websites.

React was developed by Facebook (now Meta).

2. What is React.js?

React.js is an open-source JavaScript library used for building user interfaces.

It allows developers to create reusable components and manage webpage content efficiently.

React is mainly used for developing the frontend of web applications.

Example:

React can be used to create:

- Social media applications.
- E-commerce websites.
- Shopping websites.
- Dashboard applications.
- Interactive web pages.

3. Features of React.js

Some important features of React.js are:

A. Component-Based Architecture

React divides a webpage into small reusable parts called components.

For example, a website can have separate components for the header, footer, navigation bar, and login form.

B. Virtual DOM

React uses a Virtual DOM, which is a lightweight representation of the actual DOM.

It helps React identify changes and update the necessary parts of the webpage efficiently.

C. Reusability

Components can be reused in different parts of an application, reducing code repetition.

D. Fast Rendering

React efficiently updates the user interface when data changes.

E. One-Way Data Flow

Data generally flows from parent components to child components through props.

4. Advantages of React.js

- Easy to learn for developers familiar with JavaScript.
- Helps create interactive user interfaces.
- Supports reusable components.
- Makes code easier to maintain.
- Has a large developer community.
- Useful for building single-page applications.

5. What is a Single Page Application (SPA)?

A Single Page Application is a web application that loads a single HTML page and updates its content dynamically without reloading the entire page for every interaction.

React is commonly used to build SPAs.

Example: Gmail and many modern web applications use single-page application techniques.

6. Setting Up a React Project

We can create a React project using Vite.

Vite is a development tool that helps create and run modern frontend projects.

Step 1: Install Node.js

Download and install Node.js from its official website:

https://nodejs.org/

Step 2: Create a React Project

Open the terminal and enter:

npm create vite@latest my-react-app -- --template react

Step 3: Open the Project Folder

cd my-react-app

Step 4: Install Dependencies

npm install

Step 5: Start the Development Server

npm run dev

The terminal will display a local development URL. Open that URL in your browser to see the React application.

7. Basic Structure of a React Project

A React project created using Vite contains different files and folders.

File/Folder| Description
node_modules| Contains installed project packages.
public| Stores public static files.
src| Contains the main source code.
App.jsx| Contains the main application component.
main.jsx| Entry point of the React application.
index.html| Main HTML file.
package.json| Contains project details and dependencies.

8. Creating Your First React Component

The following is a simple React application.

App.jsx

function App() {
    return (
        <div>
            <h1>Welcome to React.js</h1>
            <p>My first React application.</p>
        </div>
    );
}

export default App;

main.jsx

import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.jsx';

ReactDOM.createRoot(document.getElementById('root')).render(
    <React.StrictMode>
        <App />
    </React.StrictMode>
);

Output:

Welcome to React.js
My first React application.

9. Difference Between React and JavaScript

JavaScript| React.js
JavaScript is a programming language.| React is a JavaScript library.
Used for general programming and web development.| Mainly used for building user interfaces.
Can directly manipulate the DOM.| Uses a Virtual DOM to manage UI updates.
Does not require components.| Encourages component-based development.
