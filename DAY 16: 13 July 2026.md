Day 16 – Introduction to Node.js

1. Introduction

Today, I learned about Node.js, which is an important part of MERN Stack Development.

Node.js is a JavaScript runtime environment that allows us to run JavaScript code outside a web browser. It is mainly used for backend development.

Earlier, JavaScript was mostly used in browsers to make websites interactive. With Node.js, we can also use JavaScript to create servers and backend applications.

2. What is Node.js?

Node.js is an open-source, cross-platform JavaScript runtime environment built on Chrome's V8 JavaScript engine.

It allows developers to use JavaScript for server-side programming.

Features of Node.js

1. Open Source: It is freely available.
2. Cross Platform: It works on Windows, Linux and macOS.
3. Fast Execution: It uses Google's V8 JavaScript engine.
4. Asynchronous: It can handle tasks without waiting for every task to finish.
5. Event Driven: It uses events to manage operations.
6. Scalable: It can handle many simultaneous connections.

3. Uses of Node.js

Node.js is used for:

- Developing backend applications.
- Creating web servers.
- Building REST APIs.
- Developing real-time applications like chat applications.
- Connecting applications with databases.
- Developing streaming applications.

4. What is the V8 Engine?

The V8 Engine is a JavaScript engine developed by Google.

It converts JavaScript code into machine code so that the computer can execute it efficiently.

Node.js uses the V8 engine to run JavaScript outside the browser.

5. What is NPM?

NPM stands for Node Package Manager.

It is used to install and manage packages and libraries required for Node.js projects.

Common NPM Commands

Command| Description
"npm -v"| Checks NPM version
"npm init"| Creates a package.json file
"npm init -y"| Creates package.json with default settings
"npm install"| Installs project dependencies
"npm install package-name"| Installs a particular package
"npm uninstall package-name"| Removes a package

6. Installing Node.js

Steps to install Node.js:

1. Visit the official website: https://nodejs.org/
2. Download the suitable version for your operating system.
3. Run the installer.
4. Follow the installation instructions.
5. Open the terminal or command prompt.
6. Check the installation using these commands:

node -v
npm -v

These commands display the installed Node.js and NPM versions.

7. First Node.js Program

Create a file named "app.js".

Code:

console.log("Hello World!");
console.log("Welcome to Node.js");

Run the program:

node app.js

Output:

Hello World!
Welcome to Node.js

This program uses "console.log()" to display messages in the terminal.

8. Creating a Simple HTTP Server

Node.js provides a built-in HTTP module that helps us create web servers.

Code:

const http = require("http");

const server = http.createServer((req, res) => {
    res.write("Welcome to my Node.js Server");
    res.end();
});

server.listen(3000, () => {
    console.log("Server is running on port 3000");
});

Run the program:

node server.js

Open this address in a browser:

http://localhost:3000

Output on the webpage:

Welcome to my Node.js Server

Explanation:

- "require("http")" imports the HTTP module.
- "createServer()" creates an HTTP server.
- "req" represents the incoming request.
- "res" represents the response sent to the client.
- "res.end()" finishes the response.
- "listen(3000)" starts the server on port 3000.

9. Difference Between JavaScript and Node.js

JavaScript| Node.js
JavaScript is a programming language.| Node.js is a runtime environment.
Commonly runs in web browsers.| Runs JavaScript outside the browser.
Used to make webpages interactive.| Used for backend development and servers.
Provides browser features like DOM access.| Provides server-side features like file and HTTP modules.

10. Advantages of Node.js

1. It uses JavaScript for backend development.
2. It provides fast execution.
3. It supports asynchronous programming.
4. It has a large package ecosystem through NPM.
5. It is useful for developing scalable applications.
6. It allows developers to use JavaScript on both frontend and backend.
