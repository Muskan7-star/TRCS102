1. Introduction

2. What are Functions?

A function is a block of code designed to perform a particular task. It runs when it is called.

Functions help us reuse code and reduce repetition.

Syntax:

function functionName() {
    // Code to execute
}

functionName();

Example:

function greet() {
    console.log("Hello, Welcome to JavaScript!");
}

greet();

Output:

Hello, Welcome to JavaScript!

3. Function with Parameters

Parameters are values passed to a function when it is called.

Example:

function add(a, b) {
    console.log(a + b);
}

add(10, 20);

Output:

30

4. Function with Return Statement

The "return" statement sends a value back from a function.

Example:

function multiply(a, b) {
    return a * b;
}

let result = multiply(5, 4);

console.log(result);

Output:

20

5. What are Conditional Statements?

Conditional statements are used to make decisions in a program based on certain conditions.

JavaScript provides different conditional statements:

- "if"
- "if...else"
- "else if"
- "switch"

A. if Statement

The "if" statement executes code only when the condition is true.

let age = 20;

if (age >= 18) {
    console.log("You are eligible to vote.");
}

Output:

You are eligible to vote.

B. if...else Statement

The "if...else" statement executes one block if the condition is true and another block if it is false.

let number = 7;

if (number % 2 === 0) {
    console.log("Even Number");
} else {
    console.log("Odd Number");
}

Output:

Odd Number

C. else if Statement

It is used when we need to check multiple conditions.

let marks = 75;

if (marks >= 90) {
    console.log("Grade A");
} else if (marks >= 60) {
    console.log("Grade B");
} else {
    console.log("Grade C");
}

Output:

Grade B

D. switch Statement

The "switch" statement is used to execute different blocks of code based on a value.

let day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    case 3:
        console.log("Wednesday");
        break;

    default:
        console.log("Invalid Day");
}

Output:

Tuesday

6. What are Loops?

Loops are used to execute a block of code repeatedly until a particular condition is met.

JavaScript provides different types of loops.

A. for Loop

A "for" loop is used when we know how many times we want to repeat a task.

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output:

1
2
3
4
5

B. while Loop

A "while" loop executes as long as the given condition is true.

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Output:

1
2
3
4
5

C. do...while Loop

A "do...while" loop executes the code at least once before checking the condition.

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Output:

1
2
3
4
5

7. Difference Between for, while and do...while

for Loop| while Loop| do...while Loop
Used when the number of repetitions is known.| Used when repetitions depend on a condition.| Executes at least once.
Checks condition before execution.| Checks condition before execution.| Checks condition after execution.
Initialization, condition, and update are written together.| Initialization and update are written separately.| Condition is checked at the end.

8. Practical Program

Program to Check Whether a Number is Positive, Negative or Zero

let number = 10;

if (number > 0) {
    console.log("Positive Number");
} else if (number < 0) {
    console.log("Negative Number");
} else {
    console.log("Zero");
}

Output:

Positive Number

Program to Print a Multiplication Table

let number = 5;

for (let i = 1; i <= 10; i++) {

5 x 2 = 10

5 x 5 = 25
5 x 6 = 30

5 x 8 = 40

5 x 10 = 50
