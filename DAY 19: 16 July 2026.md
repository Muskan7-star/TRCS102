# CRUD Operations and Mongoose

## Aim

To understand CRUD operations and learn how to perform Create, Read, Update, and Delete operations in MongoDB using Mongoose.

## 1. Introduction to CRUD Operations

CRUD stands for four basic operations used to manage data in a database.

- **Create:** Add new data.
- **Read:** Retrieve existing data.
- **Update:** Modify existing data.
- **Delete:** Remove existing data.

These operations are commonly used in web applications to manage information.

## 2. What is Mongoose?

Mongoose is an Object Data Modeling (ODM) library for MongoDB and Node.js.

It makes it easier to interact with MongoDB using JavaScript.

**Features of Mongoose:**

- Provides a structured way to work with MongoDB.
- Defines schemas and models.
- Supports data validation.
- Makes database operations easier.
- Helps manage relationships between data.

## 3. What is a Schema?

A Schema defines the structure of documents in a MongoDB collection.

It specifies the fields, their data types, and validation rules.

**Example:**

```javascript
const mongoose = require('mongoose');

const patientSchema = new mongoose.Schema({
    name: String,
    age: Number,
    department: String
});
```

## 4. What is a Model?

A Model is created from a Schema and is used to interact with a MongoDB collection.

**Example:**

```javascript
const Patient = mongoose.model('Patient', patientSchema);
```

Here, `Patient` is the model used to perform database operations.

## 5. Installing Mongoose

First, create a Node.js project and install Mongoose.

```bash
npm init -y
npm install mongoose
```

## 6. Connecting Node.js with MongoDB

Create a file named `server.js`.

```javascript
const mongoose = require('mongoose');

mongoose.connect('mongodb://127.0.0.1:27017/HospitalDB')
.then(() => {
    console.log('MongoDB Connected Successfully');
})
.catch((error) => {
    console.log(error);
});
```

**Explanation:**

- `require('mongoose')` imports Mongoose.
- `mongoose.connect()` connects the application to MongoDB.
- `.then()` runs when the connection is successful.
- `.catch()` handles connection errors.

## 7. CRUD Operations Using Mongoose

### A. CREATE – Insert Data

The Create operation is used to add new records to the database.

```javascript
const patient = new Patient({
    name: 'Muskan',
    age: 20,
    department: 'Cardiology'
});

patient.save();
```

### B. READ – Retrieve Data

The Read operation is used to fetch records from the database.

```javascript
Patient.find()
.then((data) => {
    console.log(data);
});
```

### C. UPDATE – Modify Data

The Update operation is used to change existing records.

```javascript
Patient.updateOne(
    { name: 'Muskan' },
    { age: 21 }
);
```

### D. DELETE – Remove Data

The Delete operation is used to remove records from the database.

```javascript
Patient.deleteOne({ name: 'Muskan' });
```

## 8. Complete CRUD Example

```javascript
const mongoose = require('mongoose');

mongoose.connect('mongodb://127.0.0.1:27017/HospitalDB')
.then(async () => {
    console.log('MongoDB Connected');

    const patientSchema = new mongoose.Schema({
        name: String,
        age: Number,
        department: String
    });

    const Patient = mongoose.model('Patient', patientSchema);

    // CREATE
    await Patient.create({
        name: 'Muskan',
        age: 20,
        department: 'Cardiology'
    });
    console.log('Patient Added');

    // READ
    const patients = await Patient.find();
    console.log('Patient Records:', patients);

    // UPDATE
    await Patient.updateOne(
        { name: 'Muskan' },
        { age: 21 }
    );
    console.log('Patient Updated');

    // DELETE
    await Patient.deleteOne({ name: 'Muskan' });
    console.log('Patient Deleted');

    await mongoose.disconnect();
})
.catch((error) => {
    console.log(error);
});
```

**Expected Output:**

```text
MongoDB Connected
Patient Added
Patient Records: [ ... ]
Patient Updated
Patient Deleted
```

*Note: This example uses a local MongoDB server. The commands execute sequentially, and the patient record is deleted at the end.*

## 10. Difference Between MongoDB and Mongoose

| MongoDB | Mongoose |
|---|---|
| NoSQL database | ODM library |
| Stores data | Helps interact with stored data |
| Uses collections and documents | Uses schemas and models |
| Database technology | Works with MongoDB and Node.js |
