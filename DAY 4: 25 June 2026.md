Topic: HTML Tables

1. Objective

To understand HTML tables and learn how to create, design and organize data in rows and columns using different HTML table tags and attributes.

2. Introduction

HTML tables are used to display data in a structured format consisting of rows and columns. They help organize information and make it easier for users to read and understand.

HTML tables are commonly used for:

- Student marksheets
- Employee records
- Attendance sheets
- Product details
- Timetables
- Price lists

HTML provides different tags and attributes to create and manage tables.

3. Basic Structure of an HTML Table

An HTML table is created using the "<table>" tag. It contains rows and columns.

Important HTML Table Tags

HTML Tag| Description
"<table>"| Defines an HTML table
"<tr>"| Defines a table row
"<th>"| Defines a table heading
"<td>"| Defines a table data cell
"<caption>"| Adds a title to the table
"<thead>"| Groups the header content
"<tbody>"| Groups the main table content
"<tfoot>"| Groups the footer content

Basic Syntax

<table>
    <tr>
        <th>Heading 1</th>
        <th>Heading 2</th>
    </tr>

    <tr>
        <td>Data 1</td>
        <td>Data 2</td>
    </tr>
</table>

4. Creating a Basic HTML Table

The following example shows how to create a simple student details table.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Student Details</title>
</head>
<body>

    <h2>Student Information</h2>

    <table border="1">
        <tr>
            <th>Name</th>
            <th>Roll Number</th>
            <th>Course</th>
        </tr>

        <tr>
            <td>Muskan</td>
            <td>101</td>
            <td>BTech</td>
        </tr>

        <tr>
            <td>Rahul</td>
            <td>102</td>
            <td>BCA</td>
        </tr>

        <tr>
            <td>Priya</td>
            <td>103</td>
            <td>BSc</td>
        </tr>

    </table>

</body>
</html>

Explanation

- The "<table>" tag creates the table.
- The "<tr>" tag creates a new row.
- The "<th>" tag creates bold heading cells.
- The "<td>" tag displays normal data.
- The "border" attribute adds a border around the table.

5. HTML Table with Caption

The "<caption>" tag is used to provide a title or heading for a table. It helps users understand the purpose of the table.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Table Caption</title>
</head>
<body>

    <table border="1">

        <caption>Student Marks Record</caption>

        <tr>
            <th>Name</th>
            <th>Subject</th>
            <th>Marks</th>
        </tr>

        <tr>
            <td>Muskan</td>
            <td>HTML</td>
            <td>90</td>
        </tr>

        <tr>
            <td>Rahul</td>
            <td>CSS</td>
            <td>85</td>
        </tr>

    </table>

</body>
</html>

Explanation

The "<caption>" tag displays the title of the table. It is generally placed immediately after the opening "<table>" tag.

6. Colspan Attribute

The "colspan" attribute is used to merge two or more columns into a single cell.

It is useful when a heading needs to cover multiple columns.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Colspan Example</title>
</head>
<body>

    <h2>Student Information</h2>

    <table border="1">

        <tr>
            <th colspan="3">Student Details</th>
        </tr>

        <tr>
            <th>Name</th>
            <th>Roll Number</th>
            <th>Course</th>
        </tr>

        <tr>
            <td>Muskan</td>
            <td>101</td>
            <td>BTech</td>
        </tr>

    </table>

</body>
</html>

Explanation

Here, "colspan="3"" combines three columns into one cell.

7. Rowspan Attribute

The "rowspan" attribute is used to merge two or more rows into a single cell.

It helps avoid repeating the same information in multiple rows.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Rowspan Example</title>
</head>
<body>

    <h2>Student Subjects</h2>

    <table border="1">

        <tr>
            <th>Name</th>
            <th>Subject</th>
        </tr>

        <tr>
            <td rowspan="2">Muskan</td>
            <td>HTML</td>
        </tr>

        <tr>
            <td>CSS</td>
        </tr>

    </table>

</body>
</html>

Explanation

Here, "rowspan="2"" combines two rows in the Name column. The name Muskan appears in one cell covering both subject rows.

8. Table Using thead, tbody and tfoot

HTML provides three important tags to divide a table into different sections.

1. "<thead>"

It is used to group the heading section of a table.

2. "<tbody>"

It is used to group the main data or body content of a table.

3. "<tfoot>"

It is used to group the footer or summary information of a table.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Table Sections</title>
</head>
<body>

    <h2>Student Marksheet</h2>

    <table border="1">

        <thead>
            <tr>
                <th>Subject</th>
                <th>Marks</th>
            </tr>
        </thead>

        <tbody>
            <tr>
                <td>HTML</td>
                <td>85</td>
            </tr>

            <tr>
                <td>CSS</td>
                <td>90</td>
            </tr>

            <tr>
                <td>JavaScript</td>
                <td>88</td>
            </tr>
        </tbody>

        <tfoot>
            <tr>
                <th>Total</th>
                <th>263</th>
            </tr>
        </tfoot>

    </table>

</body>
</html>

9. Adding CSS to HTML Tables

CSS can be used to improve the appearance of HTML tables. We can add colors, borders, spacing and alignment.

Example

<!DOCTYPE html>
<html>
<head>
    <title>Styled Table</title>

    <style>
        table {
            width: 60%;
            border-collapse: collapse;
        }

        th, td {
            border: 1px solid black;
            padding: 10px;
            text-align: center;
        }

        th {
            background-color: lightblue;
        }

        tr:hover {
            background-color: lightgray;
        }
    </style>

</head>
<body>

    <h2>Student Records</h2>

    <table>
        <tr>
            <th>Name</th>
            <th>Roll No</th>
            <th>Course</th>
        </tr>

        <tr>
            <td>Muskan</td>
            <td>101</td>
            <td>BTech</td>
        </tr>

        <tr>
            <td>Rahul</td>
            <td>102</td>
            <td>BCA</td>
        </tr>
    </table>

</body>
</html>

Explanation of CSS Properties

- "width": Sets the width of the table.
- "border-collapse": Combines table borders into a single border.
- "padding": Adds space inside table cells.
- "text-align": Aligns text inside cells.
- "background-color": Adds background color.
- "tr:hover": Changes the row background when the mouse pointer moves over it.

10. Advantages of HTML Tables

1. Tables organize information in rows and columns.
2. They make large amounts of data easier to understand.
3. They help display student records and marksheets.
4. They support merging rows and columns.
5. They can be styled using CSS.
6. They improve the presentation of tabular information.

11. Difference Between th and td

"<th>"| "<td>"
Defines a heading cell| Defines a data cell
Text is bold by default| Text is normal by default
Used for column or row headings| Used for actual table information
